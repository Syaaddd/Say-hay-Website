# Say Hi Website 👋

Website sapaan simpel dibangun dengan **React 19** + **Tailwind CSS v4**.

## Fitur

- Dark/light mode toggle (disimpan ke localStorage)
- Input nama → 6 kartu sapaan berubah otomatis
- Animasi tangan wave di hero section
- Responsive mobile-first

## Stack

- Vite 6
- React 19
- Tailwind CSS v4 (`@tailwindcss/vite`)

## Jalankan lokal

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
```
